# دليل المستخدم — نظام غاندي للسنترالات

## أول تشغيل
1. شاشة التفعيل: ابعت البصمة للمطور (01098811581) وحط المفتاح اللي يوصلك.
2. ادخل بـ `admin` / `1234` وغيّر كلمة المرور فوراً.
3. **الإعدادات**: اسم المحل، اللوجو، التليفونات، مقاس الإيصال والطابعة، شروط الصيانة.
4. **النسخ الاحتياطي**: اختار مكانين أو تلاتة (فلاشة / هارد تاني / فولدر جوجل درايف).
5. **الخزن والمحافظ**: عدّل أرقام المحافظ وحدودها والعمولات، وحط الرصيد الافتتاحي لكل حساب.
6. **الموظفين**: ضيف الفنيين (علّم "فني صيانة") ونسبة العمولة.
7. **المستخدمين**: اعمل حساب لكل موظف وحدد صلاحياته (فيه قوالب جاهزة).
8. **الأصناف**: ضيف الأصناف أو استوردها من Excel (CSV).

## الاختصارات
F1 بيع — F2 البحث في البيع — F9 دفع — F3 صيانة — F4 كاش ورصيد — F5 الليمت — F6 أصناف — F7 عملاء — F8 تقارير — Esc قفل النافذة.

## البيع
- امسح الباركود أو IMEI الجهاز واضغط Enter. الموبايلات بـ IMEI بيظهر لك تختار الجهاز.
- الدفع: ممكن تقسم المبلغ على أكتر من حساب. لو المدفوع أقل = آجل على العميل.
- **تقسيط**: اختار العميل ← "بيع بالتقسيط" ← المقدم والشهور والزيادة والضامن ← بيطبع العقد.
- **تعليق**: لو العميل هيرجع، علّق الفاتورة وكمّل مع غيره.

## الصيانة
استلام ← (فحص / انتظار قطع / جاري الإصلاح / جاهز) ← تسليم.
- القطع بتتسحب من المخزن تلقائياً، والمصنعية بتتحسب منها عمولة الفني.
- لما تخلي الحالة "جاهز" البرنامج يعرض يبعت واتساب للعميل.
- بعد التسليم تقدر تعمل "استلام ضمان" مربوط بالتذكرة الأصلية.

## كاش ورصيد وفواتير
- **سحب كاش**: العميل يحول لمحفظتك ← تديله (المبلغ − العمولة).
- **إيداع/تحويل**: العميل يديك (المبلغ + العمولة) ← تحوّل له.
- **تحويل رصيد**: اختار الشبكة والقيمة — الربح حسب معامل التكلفة.
- **فواتير**: فوري/أمان… بالعمولة.
- **الليمت**: من الخزن والمحافظ حط لكل خط حد الإرسال والاستقبال اليومي والشهري. شاشة "متابعة ليمت المحافظ" (F5) بتوريك المستخدم والمتبقي لكل خط، ولو عملية هتعدّي الحد البرنامج بيمنعها ويقترح محفظة فيها مساحة.
- لتغذية رصيد المحفظة أو الشبكة: الخزن والمحافظ ← تحويل / تغذية رصيد.

## آخر اليوم
الورديات ← إغلاق الوردية ← عد الفلوس ← بيطبع تقرير العجز/الزيادة. والتقارير ← التقرير اليومي / ملخص الأرباح.
