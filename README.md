# نظام غاندي لإدارة السنترالات ومحلات الموبايل والصيانة
**Ghandi Central** — برنامج ويندوز يعمل بدون إنترنت
برمجة وتطوير: **م. محمد علي — 01098811581**

> ⚠️ الريبو ده لازم يفضل **Private** لأن فيه مفتاح توليد التراخيص (`keygen/`).

## المميزات
- **نقطة بيع** بالباركود و IMEI، تعليق فواتير، دفع متعدد (كاش/فودافون كاش/إنستاباي/فيزا)، آجل، **بيع بالتقسيط**، عرض سعر، إيصال حراري 80/58 أو A4.
- **الصيانة**: إيصال استلام بباركود (نسختين)، باسورد ونمط الفتح، المرفقات، الفني، حالات الإصلاح، قطع غيار من المخزن، مصنعية، فني خارجي، عربون، تسليم، ضمان واستلام ضمان، ملصق للجهاز، رسالة واتساب "جهازك جاهز".
- **كاش ورصيد وفواتير**: سحب/إيداع محافظ (فودافون/أورنج/اتصالات/WE/إنستاباي) بعمولة تلقائية، حدود يومية وشهرية، تحويل رصيد بالشبكات بمعامل تكلفة، فوري/أمان/فواتير، إلغاء عملية بعكس الحركات.
- **المخزون**: أصناف وأقسام، تتبع الموبايلات بـ IMEI1/IMEI2، حركة الصنف، تسوية، جرد بالباركود، نواقص، استيراد/تصدير CSV، طباعة باركود بمقاسات مختلفة.
- **المشتريات** والموردين ومرتجعات المشتريات، متوسط التكلفة، كشف حساب مورد.
- **شراء الموبايلات المستعملة** مع بيانات البائع والرقم القومي وصورة البطاقة وإقرار بيع للطباعة.
- **العملاء**: آجل وتحصيل وسند قبض وكشف حساب، **الأقساط** بجدول وضامن وعقد وغرامات وتذكير واتساب.
- **الحجوزات وطلبات العملاء** بعربون.
- **الخزن والمحافظ**: أرصدة، تحويل/تغذية رصيد، رأس مال ومسحوبات، تسوية، كشف حساب.
- **المصروفات والإيرادات الأخرى**، **الورديات** وتقفيل الدرج (عجز/زيادة)، **الموظفين والرواتب** وعمولة الفنيين.
- **20 تقرير** (أرباح وخسائر، يومي، أصناف، أقسام، فنيين، خدمات مالية، مخزون، راكد، أقساط، مديونيات…) طباعة/PDF/Excel.
- **المستخدمين والصلاحيات** (32 صلاحية + قوالب كاشير/فني/مشرف)، سجل عمليات، قفل شاشة تلقائي، وضع ليلي.
- **نسخ احتياطي** تلقائي في المكان الافتراضي + 3 أماكن يختارها صاحب المحل، واسترجاع.
- **تفعيل ببصمة الجهاز** ومدة (أسبوع/شهر/سنة/مدى الحياة) بتوقيع Ed25519 — مايتكسرش بتعديل الملفات، ومنع الرجوع بتاريخ الجهاز.

## الرفع على جيت هب وبناء ملف التثبيت
1. اعمل ريبو **Private** باسم `ghandi-central` على حسابك `gandih15`.
2. ارفع كل محتويات الفولدر (Upload files ← اسحب الملفات كلها بما فيها `.github`).
3. من تبويب **Actions** هتلاقي "Build Windows Installer" اشتغل لوحده (أو اضغط Run workflow).
4. بعد ما يخلص (حوالي 5-8 دقايق) ادخل على الـ Run ← **Artifacts** ← نزّل `Ghandi-Central-Setup` وجواه `Ghandi-Central-Setup-1.0.0.exe` (64 و 32 بت في ملف واحد).
5. لعمل إصدار: اعمل Tag زي `v1.0.1` وهيتعمل Release فيه ملف التثبيت.

### البناء على جهازك (اختياري)
```
npm install
npm run dist
```
(محتاج Node.js 18 على الجهاز، والملف بيطلع في فولدر `dist`)

## التفعيل
- العميل يفتح البرنامج ← تظهر **البصمة** ← يبعتها لك (فيه زرار واتساب جاهز).
- إنت تفتح `keygen/keygen.html` على كروم/إيدج ← تحط البصمة والمدة واسم المحل ← تبعتله المفتاح.
- أو بالنود: `node keygen/keygen.js <البصمة> <الأيام> "اسم المحل"` (0 = مدى الحياة).
- التجديد: مفتاح جديد بنفس البصمة يتحط من شاشة التفعيل أو لوحة المطور.

## أماكن البيانات على جهاز العميل
- البيانات: `%APPDATA%\Ghandi Central\data\db.json` (منفصلة عن البرنامج — التحديث مايمسحهاش)
- النسخ الافتراضية: `Documents\Ghandi-Central-Backups`
